# SunfishDesk

**SunfishDesk** is a creative SaaS landing page concept that combines modern tech design with an immersive ocean atmosphere.

Instead of a traditional cursor, a small sunfish swims through the page and follows the user’s mouse, turning the website itself into an interactive ocean environment.

The goal of this project is to explore how storytelling, animation and branding can transform a simple landing page into a memorable digital experience.

---

## 🐟 Core Concept

The website simulates diving into the ocean.

As the user scrolls:

- the environment gradually becomes deeper and darker
- lighting effects change like underwater sunlight
- bubbles and particles create depth
- the fish cursor swims through the interface

The entire layout is designed to feel like a **digital ocean ecosystem**.

---

## ✨ Features

- 🐟 **Animated fish cursor** that follows the user
- 🌊 **Dynamic ocean atmosphere**
- 💡 **Underwater light rays**
- 🫧 **Floating bubble system**
- 🌊 **Animated surface waves**
- 🎨 **Modern SaaS-style UI**
- 📱 **Fully responsive layout**
