# CLAUDE.md

## Projekt
SunfishDesk – Firmenwebseite

## Ziel
Diese Codebasis dient zur Entwicklung einer hochwertigen, modernen und vertrauenswürdigen Firmenwebseite für **SunfishDesk**.  
SunfishDesk wird als modernes Software- und Digitalisierungskonzept positioniert, mit Fokus auf Helpdesk-Systeme, Wissensmanagement, Support-Prozesse, interne Serviceportale und strukturierte Informationsverwaltung.

Die Webseite soll wie der Auftritt eines echten, professionellen Softwareunternehmens wirken.

## Designprinzipien
- responsive first
- klare visuelle Hierarchie
- saubere Grid-Struktur
- konsistente Abstände
- moderne UI-Komponenten
- hochwertige Hover-Effekte
- semantisch sauberes Markup
- wartbarer Code
- keine unnötige visuelle Überladung

---

## Technische Anforderungen
Bevorzugt:
- React / Next.js oder sauberes HTML/CSS/JS
- komponentenbasierte Struktur
- gut lesbarer und sauber organisierter Code
- direkt lauffähiges Ergebnis
- keine unfertigen Platzhalter

---

## Was vermieden werden soll
- generische Stock-Startup-Texte
- kitschige Fischgrafiken
- überladene Layouts
- zu viele Farben
- unruhige Animationen
- unseriöse Claims
- halbfertige Dummy-Inhalte
